# Development Update - 2026-04-01

## Focus Of The Day

We cleaned up the project structure and moved away from the mixed static prototype so the app could grow properly as a multi-page product.

## Major Decisions

- decided to separate `local` and `web multiplayer` so unfinished room/socket work would not keep breaking local mode
- agreed the project should use `Next.js + TypeScript + .tsx` for better multi-page structure and easier Vercel deployment
- kept multiplayer isolated for later instead of continuing to mix roadmap phases

### 2. Split the app into clear routes

This was done so:

## Visual Direction

We used a more premium neon/esports-style inspiration rather than a plain settings-and-board layout.

Direction taken:

- stronger sci-fi glow
- board-first presentation
- cleaner competitive HUD feel
- celebratory winner state

Direction intentionally not copied literally:

- no heavy isometric 3D board yet
- no overly busy particle overload
- readability still prioritized
